# Какой файл АРПС делает конвертер

АРПС 1.10 это открытый формат обмена сметами между программами. Описание полей опубликовано в справке нескольких сметных программ, например [АВС](https://help.abccenter.ru/abc-ru/---1_10.html) и [А0](https://gk-infostroy.ru/spravka/a0/prilozhenie_1__format_arps_1_10.htm).

Конвертер пишет файл так же, как его выгружает сам Estimate 1.9: мы сравнивали с его собственным экспортом.

## Общее

- Текстовый файл в кодировке DOS (cp866), строки разделены CRLF, расширение `.arp`.
- Одна строка = одна запись, поля разделены знаком `#`. Знак `#` внутри текста конвертер заменяет пробелом.
- Первое поле записи: её тип.
- Дробная часть через точку, объём с четырьмя знаками: `2.5000`.

## Какие записи и поля заполняются

| Тип | Что это | Что пишем |
|---|---|---|
| 1 | Заголовок файла | `1#АРПС 1.10#SmetaARPS#0.7` |
| 3 | Шапка сметы, 20 полей | объект (3), номер (4), название (5), уровень цен `2001` (15) |
| 10 | Раздел | уровень `0`, номер, название |
| 20 | Позиция, 29 полей | номер, шифр, единица, наименование, объём (26), признак `0` (27); стоимостные поля пустые |
| 30 | Ресурс | одна служебная строка `Оплата труда рабочих` у позиции с шифром, см. [estimate-import.md](estimate-import.md) |

## Шифры

Шифр пишется так, как в базе Estimate, без буквенной приставки: `ТЕР08-01-001-01` и `08-01-001-01` дают одно и то же. У ремонтных и монтажных расценок остаётся буква: `ТЕРр61-1-1` превращается в `р61-1-1`. Как Estimate находит такие шифры, ещё не проверено.

## Таблица на входе

Колонки ищутся по заголовкам, порядок любой:

- **Шифр** (обязательно): шифр, код, обоснование
- **Объём** (обязательно): объём, объем, кол-во, количество
- **Наименование**: наименование, название, работы, наименование работ
- **Ед. изм.**: ед. изм., единица, единица измерения
- **Раздел**: раздел

Номер сметы, название и объект берутся из строк над таблицей: «Смета №: ЛС-1», «Название: ...», «Объект: ...». В Excel подпись в колонке A, значение в колонке B.

Раздел: строка, где заполнена только колонка «Раздел» или только наименование. Строки «Итого», «Всего», «НДС», «Накладные», «Сметная прибыль» пропускаются.
