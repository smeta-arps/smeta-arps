# Загрузка файла .arp в Estimate

Проверено на Estimate 1.9 с базой ТСНБ ТЕР-2001 Самарской области редакции 2014 года, код района 36.2014. Если у вас другая версия или база, напишите через форму «Проверил в своей программе».

## Шаги

1. Откройте в Estimate любую смету из архива. Пока ни одна смета не открыта, меню «Обмен» неактивно.
2. Меню **Обмен → АРПС 1.10 импорт**. Выберите папку в архиве и нажмите кнопку импорта.
3. Укажите файл `.arp`. Привязку на этом шаге можно не трогать. Нажмите **Применить**, смета появится в архиве.
4. Откройте титульный лист: **Сметы → Открыть → Локальная смета**, выберите загруженную смету, **Редактировать**.
5. Вкладка **Свойства**: выберите «С привязкой» и код района, нажмите **Сохранить**.
6. На вопрос «Вы изменили район привязки. Заменить стоимость ресурсов?» нажмите **Применить**.

Откройте смету. Строки с пометкой «Т» взяты из базы: наименование, единица, зарплата, машины, материалы. Зелёные строки: шифра не было или в базе его нет, их нужно доделать вручную.

## Если расценки пустые

Смета уже была привязана к нужному району, и шаг 6 не появился. Тогда на шаге 5 сначала выберите «Без привязки» и сохраните, затем повторите шаги 4-6.

## Почему так

При импорте Estimate берёт цены только из самого файла, а в нашем файле их нет. Расценки подставляет перепривязка к району: программа находит шифр в базе и заменяет содержимое позиции. Сработает она только для позиций, у которых в файле есть хотя бы одна строка ресурса. Поэтому конвертер добавляет к каждой позиции с шифром служебную строку «Оплата труда рабочих», а Estimate заменяет её настоящей расценкой.

Названия работ из вашей таблицы при этом заменяются на названия из базы. Это нормально.

Начисления (накладные, сметная прибыль, индексы, лимитированные затраты) задаются в Estimate как обычно, после импорта.
