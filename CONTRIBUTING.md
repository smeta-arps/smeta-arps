# Как помочь проекту

Спасибо, что заглянули. Помочь можно без знания программирования.

## Проверить в своей программе

Это самое полезное. Мы проверили только Estimate 1.9, а программ и версий много.

1. Скачайте папку [test-kit](test-kit) или один файл `primer.arp` из неё.
2. Загрузите его в свою сметную программу по инструкции из [test-kit/README.md](test-kit/README.md).
3. Откройте **Issues** → **New issue** → «Проверил в своей программе» и заполните форму.

Отрицательный результат тоже результат. «Не открылось в такой-то версии» помогает не меньше, чем «всё встало».

## Сообщить об ошибке

**Issues** → **New issue** → «Ошибка в конвертере». Опишите, какой файл загружали и что получилось. Если можете, приложите файл, заархивированный в .zip: GitHub не принимает файлы .arp напрямую.

## Предложить идею

**Issues** → **New issue** → «Предложение».

## Чего не присылать

- Сметы с настоящими данными заказчиков: организации, адреса, фамилии, номера договоров. Замените их на условные.
- Чужие программы, их руководства, сметно-нормативные базы, сборники цен и их части. Их нельзя распространять, такие файлы удаляем.

## Изменения в коде

1. Сделайте копию репозитория (Fork), внесите изменения, откройте Pull Request.
2. Логика конвертера живёт в двух местах: `src/converter.js` (сайт) и `cli/excel2arps.py` (командная строка). Меняйте обе, они должны выдавать одинаковый файл.
3. Перед отправкой:

```
python tests/make_expected.py
python src/build.py
node tests/site_test.mjs
```

Последняя команда должна закончиться словами «Всё совпало».

Пишем по-русски: описание, комментарии в коде, обсуждения. Имена файлов, папок и переменных латиницей.
