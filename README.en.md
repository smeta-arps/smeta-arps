# Smeta v ARPS

A free converter for Russian construction cost estimates (smeta). It turns a table from Word, Excel or CSV into an **ARPS 1.10** exchange file that Estimate and other Russian estimating programs can import. Everything runs in the browser, no file leaves the computer.

The project, its documentation and its discussions are in Russian, because the estimating programs and the regulations it works with are Russian. See [README.md](README.md).
